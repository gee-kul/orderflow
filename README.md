# OrderFlow

OrderFlow — backend-сервис для управления жизненным циклом заказов и надёжной обработки событий, связанных с заказами.

> Статус проекта: в разработке.

## Цель проекта

Цель проекта — разработать приближенный к production Go-сервис и продемонстрировать практические навыки работы с HTTP API, PostgreSQL, транзакциями, асинхронной обработкой, тестированием, наблюдаемостью и CI.

## Первая версия проекта — MVP

Первая версия будет поддерживать:

- создание заказа с одним или несколькими товарами;
- получение заказа по его идентификатору;
- получение списка заказов;
- пагинацию списка заказов;
- фильтрацию заказов по статусу;
- изменение статуса заказа;
- отмену заказа;
- проверку входящих данных;
- хранение заказов и товаров в PostgreSQL.

## Планируемые инженерные возможности

После реализации MVP в проект будут добавлены:

- паттерн Transactional Outbox;
- фоновый worker;
- брокер сообщений;
- повторные попытки с задержкой;
- идемпотентная обработка событий;
- структурированные логи;
- метрики и трассировка;
- корректное завершение приложения;
- unit- и integration-тесты;
- автоматические проверки в CI.

## Что не входит в первую версию

В первой версии не будет:

- frontend-приложения;
- подключения настоящей платёжной системы;
- полноценного каталога товаров;
- реальной отправки электронных писем или SMS;
- разделения проекта на множество микросервисов.
